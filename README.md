# Scout & Sage

A landing-page clone inspired by [Jack & Jill](https://www.jackandjill.ai/), rebranded as **Scout & Sage**:

- **Scout** — AI career agent for candidates (analogous to Jack)
- **Sage** — AI hiring agent for companies (analogous to Jill)

Built with Next.js 16, React 19, and Tailwind CSS 4.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
